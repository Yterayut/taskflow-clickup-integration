## 🖥️ **Getting Started Tutorial**

### **Step 1: Login**
1. **Open your browser** and go to: `http://localhost:3000` (or your assigned URL)
2. **Enter your credentials**:

1. **Complete your profile**:

## 📋 **Core Features Training**

### **🎯 Task Management**

#### **Viewing Tasks**
1. **Navigate to Tasks section** (location varies by role)
2. **Use filters** to find specific tasks:
   - **Status**: Todo, In Progress, Review, Done
   - **Priority**: Low, Normal, High, Urgent
   - **Assignee**: Filter by person
   - **Due Date**: Filter by date range
3. **Sort tasks** by clicking column headers
4. **Search** using the search box for quick finding

#### **Working with Tasks**
1. **Click on any task** to view details
2. **Update task status** by clicking the status dropdown
3. **Add comments** in the task detail view
4. **Upload attachments** using the attachment button
5. **Set priority** using the priority selector

#### **Creating New Tasks** (Manager/Team Lead only)
1. **Click "New Task"** button
2. **Fill in task details**:
   - Task name and description
   - Assign to team member
   - Set due date and priority
   - Add any additional notes
3. **Save task** to create and notify assignee

### **⏰ Attendance Management**

#### **For Employees: Daily Attendance**
1. **Clock In**:
   - Go to Attendance section
   - Click "Clock In" when you start work
   - System records your start time
2. **Break Management**:
   - Click "Start Break" when taking breaks
   - Click "End Break" when returning
3. **Clock Out**:
   - Click "Clock Out" when finishing work
   - Review your daily hours before confirming

#### **Leave Requests**
1. **Request Leave**:
   - Click "Request Leave" in Attendance section
   - Select leave type and dates
   - Add reason and any supporting documents
   - Submit for approval
2. **Track Requests**:
   - View status of your leave requests
   - Get notifications when approved/rejected

#### **For Managers/Team Leads: Attendance Oversight**
1. **View Team Attendance**:
   - Access Team Attendance section
   - See real-time status of team members
   - Review daily/weekly attendance reports
2. **Approve Leave Requests**:
   - Review pending leave requests
   - Approve or reject with comments
   - System automatically updates schedules

### **📊 Reports and Analytics**

#### **Viewing Reports**
1. **Navigate to Reports section** (Manager/Team Lead)
2. **Select report type**:
   - Team performance reports
   - Attendance summaries
   - Task completion analytics
   - Custom reports
3. **Set date ranges** and filters
4. **Generate report** and view results

#### **Exporting Data**
1. **Choose export format**: PDF, CSV, or Excel
2. **Select data range** and filters
3. **Click "Export"** to download
4. **Use exported data** for external analysis

## 🔐 **Security Best Practices**

### **Password Management**
1. **Use Strong Passwords**: At least 8 characters with mixed case, numbers, and symbols
2. **Change Default Password**: Update your password on first login
3. **Regular Updates**: Change password every 90 days
4. **Don't Share**: Never share your login credentials

### **Data Protection**
1. **Log Out**: Always log out when finished, especially on shared computers
2. **Screen Lock**: Lock your screen when away from desk
3. **Report Issues**: Immediately report any security concerns to IT

### **ClickUp Integration**
1. **OAuth Authentication**: Use official ClickUp login when prompted
2. **Permission Review**: Check what data access you're granting
3. **Regular Sync**: Data syncs automatically, but you can manually refresh if needed

## 🆘 **Troubleshooting Guide**

### **Common Issues and Solutions**

#### **🔐 Login Problems**
**Problem**: Can't log in / "Invalid credentials" error
**Solutions**:
1. Double-check email address (case-sensitive)
2. Ensure password is correct (check caps lock)
3. Try password reset if forgotten
4. Contact IT if issues persist

#### **🌐 Page Loading Issues**
**Problem**: Pages load slowly or don't load
**Solutions**:
1. **Refresh page**: Press F5 or Ctrl+R
2. **Clear browser cache**: Ctrl+Shift+Del
3. **Check internet connection**
4. **Try different browser** (Chrome, Firefox, Safari)
5. **Contact IT** if problems continue

#### **📋 Tasks Not Updating**
**Problem**: Task changes don't appear or sync
**Solutions**:
1. **Manual refresh**: Click refresh button or F5
2. **Check ClickUp connection**: Look for sync status indicator
3. **Re-authenticate ClickUp** if prompted
4. **Wait a moment**: Some updates take 1-2 minutes

#### **⏰ Attendance Issues**
**Problem**: Clock in/out not working
**Solutions**:
1. **Check time zone**: Ensure correct time zone in profile
2. **Refresh page** and try again
3. **Contact supervisor** if urgent
4. **Use manual entry** as backup (contact IT to adjust)

#### **📱 Mobile Issues**
**Problem**: Mobile interface problems
**Solutions**:
1. **Update browser**: Ensure latest version
2. **Clear mobile browser cache**
3. **Try landscape mode** for better layout
4. **Use desktop version** if needed
